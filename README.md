# supersite.github.io
# Личная библиотека
Функционал Личной библиотеки:

Авторизация и гостевой просмотр

    -При открытии сайта появляется окно с запросом пароля для редактирования (авторизация).
    -Есть возможность просматривать библиотеку без ввода пароля (только просмотр, без редактирования).
  
Коллекция медиаконтента

    -Сайт предназначен для хранения собственных коллекций книг, игр, фильмов и сериалов.
    -Каждый элемент коллекции содержит основные поля: название, тип, автор/разработчик, статус, рейтинг, обложка, описание.

Добавление и редактирование

    -Реализовано модальное окно для добавления новой записи в библиотеку или редактирования существующей.
    -Все поля формы валидируются на обязательность ввода.

Карточки и сетка

      -Все элементы отображаются в виде карточек в сетке.
      -Изображения, названия, статусы и рейтинги выводятся на каждой карточке.
      -Фильтрация и поиск
Дополнительная панель с фильтрами:

      -По типу: книги, игры, фильмы, сериалы.
      -По статусу: в планах, в процессе, завершено.
      -Поиск по названию в реальном времени.

Управление статусом и рейтингом

    -Для каждого элемента можно задать статус (планы/процесс/завершено) и выставить рейтинг (0—10).

Смена темы

    -В углу страницы размещена кнопка для смены темы оформления (например, темная/светлая).

Адаптивность

    -Интерфейс адаптивен для разных устройств и экранов.
